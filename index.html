☁️ 云同步（多设备互通）
配置后，打卡和体测数据自动同步到云端，手机、电脑数据一致。首次使用需在 Supabase 免费建一个项目（约3分钟）。
📖 首次配置教程（点开）
  1. 打开 supabase.com → 用 GitHub 账号免费注册 → New project，起名随意（如 training），数据库密码随便设一个并保存好，区域选 Singapore（国内访问快）。
  2. 项目建好后，左侧菜单点 SQL Editor → New query，粘贴下面这段并 Run：
    create table training_data (
  id text primary key,
  data jsonb,
  updated_at timestamptz default now()
);
alter table training_data enable row level security;
create policy "anon_all" on training_data
  for all using (true) with check (true);
  3. 左侧菜单 Settings → Integrations → Data API：复制 API URL（形如 https://xxxx.supabase.co，若末尾带 /rest/v1/ 也没关系，页面会自动处理）。
  4. 左侧菜单 Settings → Configuration → API Keys：复制 Publishable key（sb_publishable_ 开头；如有 Legacy keys 标签，里面的 anon public key 也可以）。
  5. 两个值填到上面的输入框，点「保存并立即同步」。之后每台设备填一次同样的两个值即可互通。
说明：publishable / anon key 只对你的训练数据表有效，相当于这把锁的钥匙，不要发到公开场所。同步策略为「最后修改优先」。

⚽ 足球日调整方案（周中约每月 1–2 次，通常晚上）

  • 替换周二节奏跑：早上不跑，晚上直接踢球；周二按跑步日饮食（2800–2900 kcal）
  • 替换周四下肢训练：晚上不练力量，直接踢球；周四按跑步日饮食
  • 替换周五容量日：晚上不练力量，直接踢球；周六做波速球恢复
  • 足球后第二天：取消力量训练，只做波速球恢复 + 泡沫轴；按恢复日饮食（2200–2300 kcal）

⚠️ 关键提醒

  • 力量训练统一晚上 8 点后，练后餐（21:00）+ 睡前餐（22:00）
  • 跑步偶尔放早上，早餐改为跑前餐（5:30 香蕉+白面包）
  • 血糖波动大：练前避免能量胶/香蕉，优先燕麦/红薯/全麦
  • 细胞外液偏低：训练日全天喝含钠电解质水
  • 右手肌肉量高：所有单侧动作左手先做，日常多用左手
  • 连续疲劳时：取消周六波速球，只做泡沫轴 + 拉伸
